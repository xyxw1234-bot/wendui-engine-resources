爱马生成案例 · 错题诊断

二次函数错题本：从“看不懂图像”到“会判断”

输入：学生错题照片和自己的错误答案。输出：错因判断、追问式讲解、同类变式题。重点是不直接代做，而是帮学生自己重建方法。

原题

已知 y = ax² + bx + c 的图像开口向上，顶点在 x 轴下方，与 x 轴有几个交点？

学生原答：1 个。理由：顶点在下面，所以只碰到一次。

错因 1：把“顶点在下方”理解成“只接触”

开口向上且顶点在 x 轴下方，图像会从下方向两边上升，通常会穿过 x 轴两次。

错因 2：没有画草图

函数图像题不要只背结论，先画开口方向、顶点位置，再看和 x 轴关系。

爱马追问式讲解

先别急着写答案。请你画一个“U”形开口向上的图像，把最低点放在 x 轴下面。现在从最低点往左右两边看，图像是不是会向上穿过 x 轴两次？所以交点数量是 2 个。

同类变式题

基础开口向下，顶点在 x 轴上方，与 x 轴有几个交点？
提升开口向上，顶点刚好在 x 轴上，与 x 轴有几个交点？为什么？
