教师版攻略学生版攻略

爱马把老师的日常工作、教学创造和成果沉淀连成一条工作流。

爱马陪学生把想法、兴趣和研究做成可用的产品成果。

老师每天面对的不只是课堂教学，还有沟通通知、事务安排、学生观察、数据分析、教研阅读、活动策划和成果复用。爱马的价值，是把这些真实需求拆成清楚任务，生成能直接使用的材料、页面、报告、工具和复用模板。

学生的成长不只发生在作业里，也发生在提问题、做项目、表达观点、探索兴趣、制作网页/海报/小游戏、准备展示和记录成长的过程中。爱马帮助学生把这些想法整理成计划、材料、产品页面和可继续修改的产品成果。

日常工作流

把老师每天最耗心力的常规事务提前：通知、计划、会议、材料、沟通，都可以从零散输入变成清楚交付。

家校沟通

家校沟通与通知材料包

把活动说明、提醒事项、问答口径和回执跟进整理成可直接发送的材料。

适合：家长通知、活动安排、班级群沟通
产物：通知正文 + 问答口径 + 跟进清单
打开真实产物
周计划

教师一周工作编排表

把备课、批改、会议、材料提交和个人事项排成可执行的周计划。

适合：班主任、学科老师、项目负责人
产物：周计划 + 风险提醒 + 每日收口
打开真实产物
日常事务

七年级组第 14 周工作复盘

把零散口述整理成周报、待跟进事项、风险提醒和下周动作。

适合：年级组、班主任、教研组日常复盘
产物：正式周报 + 进展表 + 动作清单
打开真实产物

教学支持

课堂仍然重要，但它只是爱马能力的一部分：从目标拆解、互动工具、任务单到讲评材料，都可以进入同一条工作流。

课堂工具

函数图像互动探究工具

把抽象知识点变成可运行网页，让学生在操作中理解图像变化。

适合：数学概念课、复习课、公开课展示
产物：可运行网页工具 + 使用说明
打开真实产物
任务单

语文托物言志阅读任务单

把阅读目标拆成证据提取、观点表达、评价量表和课堂追问。

适合：语文阅读课、分层任务、课堂练习
产物：可打印任务单 + 评价标准
打开真实产物
作业讲评

七年级数学作业共性问题反馈

从学生答案中生成评分概况、共性错误、讲评顺序和二次练习。

适合：作业批改后的讲评准备
产物：讲评建议 + 错因表 + 变式题
打开真实产物

学生成长与班级管理

把学生观察、谈话、班级问题和数据变化做成连续证据，而不是靠临时印象管理班级。

成长记录

学生成长观察与谈话记录

把课堂表现、作业变化、谈话要点和家校沟通整理成连续成长证据。

适合：班主任谈话、导师制、个别化支持
产物：观察证据 + 谈话提纲 + 跟进动作
打开真实产物
数据看板

班级数据与问题看板

把成绩、作业、参与度、反馈记录转成班级问题画像和下一步干预建议。

适合：阶段检测、作业反馈、班级复盘
产物：趋势看板 + 分层建议 + 干预动作
打开真实产物
家长会

家长会沟通稿与 PPT 结构

从沟通目标、班级画像到会后跟进，形成可投屏的会议材料。

适合：家长会、班级说明会、阶段沟通
产物：PPT 页面结构 + 主持稿 + 跟进清单
打开真实产物

教研研究与专业表达

把论文、政策、培训材料、项目观察转成老师能理解、能引用、能落地的表达材料。

资料速读

教研资料速读与观点卡

把政策文件、论文、培训材料变成可吸收、可引用、可落地的观点卡。

适合：教研阅读、培训复盘、方案写作
产物：三层摘要 + 引用句 + 落地建议
打开真实产物
教研简报

学校 AI 应用教研简报

把观察、问题、数据和建议整理成正式汇报材料。

适合：教研汇报、项目复盘、校内展示
产物：结构化简报 + 建议清单
打开真实产物
汇报材料

家长会沟通稿与 PPT 结构

同一套能力也能服务项目汇报、阶段复盘和会议表达。

适合：项目汇报、公开展示、培训分享
产物：PPT 结构 + 讲稿 + 会后动作
打开真实产物

成果沉淀与复用

当某些材料值得复用、展示或发布时，再进入产品成果库；爱马要让好成果找得回来、改得下去。

网页工具

函数图像互动探究工具

可运行、可展示、可复用到后续课程的产品成果。

适合：公开课展示、课程资源沉淀
产物：可运行网页工具
打开真实产物
材料模板

家校沟通与通知材料包

把通知、问答、跟进清单沉淀为下一次活动可复用模板。

适合：活动通知、家校沟通、班级事务
产物：可复用模板 + 跟进清单
打开真实产物
教研成果

学校 AI 应用教研简报

把研究、观察和建议沉淀为组织可共享的正式成果。

适合：教研汇报、校内培训、项目复盘
产物：结构化简报 + 资源链接
打开真实产物

想法孵化与自我规划

学生先有想法，再把想法变成计划、问题、项目和产品成果；爱马要陪他从“我想做”走到“我做出来”。

想法孵化

我的想法孵化板

把模糊兴趣、脑洞或问题整理成可研究、可创作、可展示的小项目。

适合：兴趣探索、项目开题、社团活动
产物：主题澄清 + 路线图 + 下一步任务
打开真实产物
个人计划

个人计划与成长记录

整理阅读、运动、比赛准备、兴趣坚持和自我管理，不只是学习计划。

适合：时间管理、习惯养成、成长记录
产物：目标拆解 + 习惯追踪 + 成长证据
打开真实产物
复习计划

期末前一周复习计划

把“我来不及了”变成每天能执行的小任务，不堆空话。

适合：期中/期末复习、薄弱学科补救
产物：一周计划 + 每日任务 + 调整规则
打开真实产物

理解诊断与学习支持

学习场景保留，但不再占据全部：爱马帮助学生看懂问题、找出卡点、形成自己的解释。

错题诊断

二次函数错题本与变式练习

从“我错了”变成错因判断、追问式讲解和同类变式题。

适合：数学错题、物理题、化学计算题
产物：错因卡 + 讲解路径 + 变式练习
打开真实产物
互动练习

二次函数闯关小游戏

用游戏化方式复习函数图像判断。

适合：自主复习、小组挑战、成果展示
产物：可运行网页小游戏
打开真实产物
作文反馈

作文《雨后的操场》五星反馈卡

先评价亮点，再指出问题，最后给出可执行修改动作。

适合：作文修改、读后感、演讲稿打磨
产物：评分卡 + 修改建议 + 原文反馈
打开真实产物

兴趣创作与项目研究

学生可以把兴趣、观察、公共议题和奇思妙想做成产品成果，而不是只完成老师布置的任务。

兴趣项目

兴趣项目路线图

围绕昆虫、游戏、音乐、运动、城市观察等兴趣，做成真正可推进的项目计划。

适合：科学观察、社团项目、个人兴趣
产物：问题定义 + 行动计划 + 成果选择
打开真实产物
研究页面

城市昆虫观察小研究

把观察记录、地点、时间和发现整理成可展示的小研究页面。

适合：科学探究、社团展示、项目学习
产物：研究页面 + 观察证据 + 反思
打开真实产物
创作产品成果

产品成果发布页

把小游戏、海报、研究报告或手工模型整理成可以展示和继续修改的产品页。

适合：个人产品成果、社团项目、创客活动
产物：产品说明 + 制作过程 + 升级计划
打开真实产物

表达展示与公共行动

观点表达、演讲展示、校园倡议和社团活动，都是学生把想法变成影响力的过程。

演讲展示

表达展示与演讲稿工作台

把观点、故事、证据和情绪组织成能上台展示的表达成果。

适合：演讲、路演、班会展示
产物：观点主线 + 证据材料 + 彩排反馈
打开真实产物
公共议题

校园节水倡议海报页

把公共议题做成一页展示产品成果。

适合：班会展示、项目路演、校园倡议
产物：展示海报页 + 倡议说明
打开真实产物
项目表达

我的想法孵化板

把一个问题从灵感、调研、方案到展示路径完整讲清楚。

适合：项目汇报、学习成果展示
产物：项目结构 + 展示提纲 + 下一步任务
打开真实产物

产品成果沉淀与成长证据

产品成果不是一次性提交物，而是学生成长证据：可以被保存、展示、复用、继续升级。

产品页

产品成果发布页

把这个产品成果是什么、服务谁、怎么做、下一版怎么升级讲清楚。

适合：产品成果集、项目展示、成长档案
产物：产品页面 + 制作过程 + 迭代计划
打开真实产物
互动产品成果

二次函数闯关小游戏

把函数图像判断做成三关小游戏，边玩边复习顶点、开口和交点。

适合：自主复习、小组挑战、成果展示
产物：可运行网页小游戏
打开真实产物
成长记录

个人计划与成长记录

把计划、产品成果、反馈、照片和反思沉淀成个人成长材料。

适合：成长档案、综合素质材料、项目复盘
产物：目标记录 + 产品成果证据 + 反思问题
打开真实产物
