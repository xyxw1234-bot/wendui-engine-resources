# 节点引擎产物卡片系统 V1

## 1. 定位

节点引擎不是文件夹，也不是普通资源库。用户、官方、组织、爱马生成的所有内容，都要被统一沉淀为“产品成果”。

产物卡片系统的目标是：把五花八门的 AI 输出物，统一包装成可识别、可打开、可管理、可发布、可复用的产品成果。

覆盖对象包括：互动资源、工具应用、PPT、Word、PDF、Excel、图片、音频、视频、报告、任务单、项目页、课程包、成长证据包、工作流等。

## 2. 核心原则

1. 外层统一：所有产物使用统一卡片骨架，包括圆角、边框、内边距、标题层级、标签、操作区。
2. 内核可变：不同产物类型通过缩略预览区的图形语言区分，而不是让整张卡片各长各的样子。
3. 先说明用途：标题和描述必须表达“这个产物用来干什么”，不只显示文件名。
4. 权限可见：个人产物必须清楚显示私密、公开等状态；官方和组织空间不重复显示无意义的公开标签。
5. 动作克制：主动作统一为预览/打开，次动作统一为查看完整成果、分享、下载、设为公开等。
6. 真实打开：点击卡片必须优先打开右侧真实预览；有真实 URL 时右侧 iframe 加载真实 URL；无 URL 时使用统一占位预览；查看完整成果走单独标签页。
7. 角色一致：官方、个人、组织、老师、学生都使用同一视觉语法，只改变来源、权限、色彩和可操作状态。

## 3. 数据字段标准

每个产物至少应具备：

- id：唯一标识。
- name/title：产物标题。
- type：业务类型，如互动资源、工具应用、PPT课件、文档、报告、图片、视频、平台、游戏。
- format：技术或文件格式，如 HTML互动、PPT、Word、PDF、图片、视频、AI工具。
- source：来源，如 official、official-app、personal、shared。
- owner/teacher：创建者或发布方。
- visibility/private/locked：权限状态。
- status：草稿、可用、生成中、待审核、已失效。
- desc：用途说明。
- subject/grade/unit/scene/category：结构化标签。
- thumbnail/cover/icon：缩略图或类型图标。
- url：真实打开地址。
- actions：可执行动作。
- relation：关联课程、项目、组织、班级或任务。

## 4. 标准卡片结构

### 4.1 顶部类型区

左侧显示类型图标和类型名，右侧显示来源或权限：

- 互动资源
- 工具应用
- 演示文稿
- 文档
- 表格
- 图片
- 视频
- 报告
- 项目页
- 课程包

状态标签示例：官方、个人、组织、私密、公开、草稿、已验收。

### 4.2 缩略预览区

缩略预览区是统一视觉的关键。外框统一，内部根据类型变化：

- 互动资源：页面窗口、节点、互动点。
- 工具应用：输入面板、输出结果、自动化流程。
- PPT：封面页、标题块、页码点。
- Word/PDF：文档页、段落线、批注点。
- Excel/表格：网格、指标条。
- 图片：图片画框、色块、景别。
- 视频：封面、播放按钮、时间条。
- 音频：波形、播放点。
- 报告：图表、摘要块。
- 项目页/平台：页面布局、导航、模块卡。

### 4.3 标题区

标题遵循“对象 + 场景 + 类型”的规则。

好标题：七下数学｜平行线的性质 · 互动应用。
差标题：新建文件、课件1、我的PPT。

### 4.4 描述区

一到两句话说明用途、适用场景、核心价值。不要堆参数。

### 4.5 标签区

最多展示 3–5 个标签。优先级：学科/年级/场景/格式/单元/分类。

### 4.6 操作区

统一动作：

- 主按钮：快速预览 / 打开应用 / 继续编辑。
- 次按钮：查看完整成果。
- 个人私密产物可显示“设为公开”。

## 5. 三种卡片规格

1. 标准卡：资源库网格默认规格。
2. 紧凑卡：最近打开、搜索结果、侧栏列表使用。
3. 展开卡：官方精选、重点推荐、项目成果使用。

当前 V1 先落地标准卡，后续再扩展紧凑卡和展开卡。

## 6. 当前落地范围

V1 先改造：

- 官方互动资源卡片。
- 官方工具应用卡片。
- 个人空间“我的产物”。
- 组织成员公开产物。
- 养马攻略资料卡。

必须保持：

- 点击卡片右侧推出预览。
- 查看完整成果可新标签页打开。
- 私密产物仍只本人可见。
- 官方卡片不显示无意义的“公开”状态。

## 7. 质量检查

每次改动后至少检查：

- PC/Pad/Mobile 是否无横向溢出。
- 老师/学生角色文案是否正确。
- 官方/个人/组织 scope 是否使用同一卡片语法。
- 点击卡片是否打开右侧预览。
- 查看完整成果是否打开单独标签页。
- 禁止出现“作品”等旧口径。
