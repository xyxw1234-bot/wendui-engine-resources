# 问对引擎网页资源

本仓库保存问对引擎当前网页、产品成果中心、官方课程资源及工具应用后端的可恢复源码快照。

## 资源范围

- 主入口及登录、个人中心页面
- 产品成果中心与教师／学生实践页面
- 官方课程资源库及资源封面
- 前端公共脚本与样式
- 工具应用 API 源码与服务配置样例
- 官方课程目录构建脚本
- `SOURCE_MANIFEST.json`：上传快照的逐文件大小与 SHA-256 校验值

## 明确不包含

- 用户数据库、会话、上传文件和生成产物
- `.env`、API Key、Token、SSH 私钥等凭证
- 服务器日志、缓存、Python 字节码
- QA 临时脚本、测试载荷、备份文件和抓取临时目录

## 恢复目标

历史生产结构：

- 静态网页：`/var/www/projects/wendui-engine/`
- 工具应用 API：`/opt/apps/wendui-engine-tool-api/app.py`
- 工具 API 本机端口：`127.0.0.1:8147`
- 公网网页前缀：`/wendui-engine/`
- 公网工具 API 前缀：`/wendui-engine-api/`

恢复时必须在服务器上单独配置运行凭证和环境变量，不得把密钥提交到本仓库。恢复完成后，应验证登录、教师／学生角色、产品成果中心、官方课程目录和工具应用“生成—保存—重新打开”完整链路。

## 仓库性质

私有恢复仓库。GitHub 提交成功只代表源码已备份，不代表当前公网服务器已经恢复。
